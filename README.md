# 📚 Real MySQL 8.0 Study

『Real MySQL 8.0 (1권)』을 함께 읽고, 매주 학습한 내용을 정리해서 업로드하는 스터디 저장소입니다.

## 🎯 진행 방식

- 매주 정해진 범위의 챕터를 읽고, 학습한 내용을 정리합니다.
- 정리한 내용은 본인 이름의 디렉터리에 주차별로 업로드합니다.

## 🗓 주차별 계획

| 주차 | 범위 | 내용 | 진행 |
|------|------|------|:----:|
| 1주차 | 1 ~ 3장 | 소개 / 설치와 설정 / 사용자 및 권한 | |
| 2주차 | 4장 | 아키텍처 | |
| 3주차 | 5 ~ 7장 | 트랜잭션과 잠금 / 데이터 압축 / 데이터 암호화 | |
| 4주차 | 8장 | 인덱스 | |
| 5주차 | 9장 | 옵티마이저와 힌트 | |
| 6주차 | 10장 | 실행 계획 | |

> 분량이 많고 중요도가 높은 챕터(4장 아키텍처, 8장 인덱스, 9장 옵티마이저, 10장 실행 계획)는 단독 주차로 배정했습니다.

## 📂 업로드 규칙

```
study-real-mysql/
├── {이름}/
│   ├── week1/
│   ├── week2/
│   └── ...
```

- 본인 이름의 디렉터리 아래에 주차별 폴더를 만들어 정리한 내용을 업로드합니다.
- 정리 파일명은 챕터 번호를 앞에 붙입니다. (예: `04-아키텍처.md`)
